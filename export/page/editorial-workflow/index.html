How content, taxonomy, and theme rendering stay decoupled.

## Editorial workflow 1. Draft pages and posts in Markdown. 2. Attach categories or tags for archive organization. 3. Render through theme templates that can later map to WordPress. ```php <?php // The frontend reads structured content, not hardcoded page markup. $route = '/post/{slug}'; ?> ``` Use `archive.php` for collections and `single.php` for individual entries.

Built to migrate cleanly.

Template parts, body classes, and compatibility tags now mirror the next WordPress extraction step.
